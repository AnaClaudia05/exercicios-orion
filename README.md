# exercicios-orion

Exercícios do Orion Bootcamp - Engenharia de IA

## Docker

O tema dos exercícios veio do meu dia a dia de auditoria de contas hospitalares: uma API que compara a quantidade de um item lançada na conta com a registrada no prontuário e mostra a diferença que ficou sem cobrar. Todos os dados de teste são inventados.

- docker/exercicio-1: Dockerfile + Compose (Hello Container)
- docker/exercicio-2: API + PostgreSQL com volume e variáveis de ambiente
- docker/exercicio-3: ambientes dev (live reload) e prod (imagem enxuta)
- docker/exercicio-extra: API + PostgreSQL + Adminer com healthcheck

Cada pasta tem um README com como rodar e o que testei.
